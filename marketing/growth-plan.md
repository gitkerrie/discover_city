# Taste China 30/60/90 天增长计划

## 当前基线

基线日期为 2026-08-22，后续比较统一使用完整的 28 天窗口。

| 指标 | 当前值 | 说明 |
| --- | ---: | --- |
| Vercel 访客 | 336 / 30 天 | 约 11.2 人/天 |
| 页面浏览量 | 381 / 30 天 | 约 1.13 页/访客 |
| 跳出率 | 95% | 地图内交互不会产生新页面浏览，需结合事件判断 |
| Search Console 已收录 | 70 页 | 另有 8 页未收录，需逐项确认原因 |
| Search Console 搜索点击 | 16 次 | 来自控制台当前报告窗口，不与 Vercel 30 天数据直接相除 |

当前热门入口包括首页，以及中文苏州、昆明、延吉、南昌和太原城市页。主要可见引荐为 Google、Facebook 和 X。

## 北极星指标

**有效访问**：访客通过搜索或带 UTM 的推广链接进入，并至少完成一次关键动作。

关键动作按意图强弱分三层：

1. 探索：`City Viewed`、`Search Completed`、`Guide Opened`、`video_food_trail_open`。
2. 深入：`City Map Opened`、`Related City Opened`、`Food Related City Opened`。
3. 传播或留存：`Favorite Changed`、`Wish List Opened`、`City Shared`、`Landing Page Shared`、`video_food_trail_favorite`。

原始搜索词不得写入分析事件；只记录语言、长度分组、结果数和最终选择。

## 第 1–14 天：数据验证冲刺

### 上线前

- 运行 `npm run check` 和 `npm run verify:map`。
- 确认 Vercel Production 环境只接收正式域名数据；日常测试使用预览部署或本地环境。
- 检查 Vercel Analytics 中页面、来源、国家、设备和 UTM 面板的当前基线。
- 在 Search Console 检查 8 个未收录 URL；仅修复应收录的 canonical 页面。

### 可选 Pro 试用

只有在所有事件已部署并验证后才开启一次 14 天试用。试用属于账号级操作，需由站点所有者确认。试用期间每天只检查一次事件是否持续进入，避免用正式域名反复人工点击污染数据。

### 第 14 天决策

- 若某入口有至少 30 次访问且关键动作率高于站点均值，进入优化与放大清单。
- 若某渠道访问不少但关键动作率接近 0，暂停该渠道。
- 若 14 天样本不足 100 次有效来源访问，不做语言或市场方向的大调整，继续采样。

## 第 15–30 天：改善站内下一步

- 优先优化已有流量的首页和五个中文城市页。
- 根据事件数据调整城市页相关推荐；避免所有城市重复推荐同一组入口。
- 把搜索无结果率、城市查看来源、收藏和分享作为验收指标。
- 暂停新增城市，除非 Search Console 已出现明确且持续的城市查询需求。

### 30 天目标

- 28 天访客达到 450–500。
- 页面浏览量/访客达到 1.25。
- 第二页访问率达到 10%。
- 关键动作率达到 10%。
- Search Console 28 天自然点击达到 25。

## 第 31–60 天：搜索需求与单一社交渠道

- 每周从 Search Console 导出查询和页面数据。
- 优先处理高曝光低点击，以及平均排名 8–20 的主题。
- 每周最多新增一篇有原创信息增量的指南，不批量生成近似页面。
- 社交渠道只保留一个，优先测试当前已有引荐的 Facebook；所有链接必须带 UTM。
- 每月联系 10 位高度相关的小型创作者，目标是获得真实引用或纠错反馈。

### 60 天目标

- 28 天访客达到 650–700。
- 页面浏览量/访客达到 1.35。
- 关键动作率达到 12%。
- Search Console 28 天自然点击达到 50。
- 获得至少 2 个相关外链或创作者引用。

## 第 61–90 天：放大已验证路径

- 只扩展已证明能带来有效访问的查询、页面和渠道。
- 优先开发“把收藏城市生成可分享美食路线”的增长功能。
- 当月访客超过 1,000 或出现稳定回访需求后，再评估邮件订阅和账号系统。

### 90 天目标

- 28 天访客达到 800–1,000。
- 页面浏览量/访客达到 1.5。
- 第二页访问率达到 20%。
- 关键动作率达到 15%。
- Search Console 28 天自然点击达到 100。
- 累计获得 3–5 个相关外链或创作者引用。

## 每周复盘模板

1. 哪三个页面带来的有效访问最多？
2. 哪个来源的关键动作率最高？
3. 哪个入口访问增长但互动下降？
4. Search Console 新出现了哪些查询？
5. 下周只做哪一个页面优化和哪一个渠道实验？
